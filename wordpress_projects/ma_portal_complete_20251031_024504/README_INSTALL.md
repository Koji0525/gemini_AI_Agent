### STEP 2: 検索ページを作成（1分）

#### A. 検索フォームページ
1. 固定ページ → 新規追加
2. タイトル: 「企業検索」
3. 本文に以下を貼り付け:
```
   [ma_search_form]
```
4. 公開

#### B. 検索結果ページ
1. 固定ページ → 新規追加
2. タイトル: 「検索結果」
3. **スラッグを「ma-search-results」に設定**（重要！）
4. 本文に以下を貼り付け:
```
   [ma_search_results]
```
5. 公開
