# 出力形式テンプレート（R007）

## 必須形式
```bash
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 1. <作業内容の説明>
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

<コマンド>

# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 2. <次の作業内容の説明>
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

<コマンド>
```

## ルール

### ✅ 良い例
```bash
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 1. TaskExecutorのメソッド一覧確認
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

grep -n "^\s*async def\|^\s*def" scripts/task_executor.py | head -20

# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 2. 特定メソッドの詳細確認
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

grep -A 30 "def execute_task" scripts/task_executor.py
```

**理由:**
- ✅ 1回のコピペで両方実行可能
- ✅ 作業番号で進捗把握
- ✅ 説明で目的が明確

### ❌ 悪い例
```
まず、TaskExecutorのメソッドを確認しましょう。
以下のコマンドを実行してください：

grep -n "def" scripts/task_executor.py

次に、詳細を見てみます。
こちらも実行してください：

grep -A 30 "execute_task" scripts/task_executor.py
```

**問題点:**
- ❌ コピペが2回必要
- ❌ 説明とコマンドが分離
- ❌ 作業番号なし

## 選択肢がある場合
```bash
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 選択肢: バックアップ方法
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

echo "どちらの方法でバックアップしますか？"
echo ""
echo "A) 自動バージョン管理（推奨・初心者向け）"
echo "   python3 tools/file_version_manager.py --backup <file> --reason <理由>"
echo ""
echo "B) 手動コピー（上級者向け）"
echo "   cp <file> _BACKUP/<file>_$(date +%Y%m%d).py"
echo ""
read -p "選択 (A/B): " choice

case $choice in
    A|a)
        echo "自動バージョン管理を実行します"
        # ここに実際のコマンド
        ;;
    B|b)
        echo "手動コピーを実行します"
        # ここに実際のコマンド
        ;;
    *)
        echo "❌ 無効な選択"
        ;;
esac
```

## 複数タスクの統合
```bash
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 一括セットアップ（5ステップ）
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

echo "🔧 開発環境セットアップ開始"

# 1. 依存パッケージインストール
echo "1/5: パッケージインストール中..."
pip install -r requirements.txt

# 2. 環境変数設定
echo "2/5: 環境変数設定中..."
cp .env.example .env

# 3. サービスアカウント配置確認
echo "3/5: サービスアカウント確認..."
if [ -f "configuration/service_account.json" ]; then
    echo "✅ service_account.json 存在"
else
    echo "❌ service_account.json が必要です"
fi

# 4. ヘルスチェック
echo "4/5: ヘルスチェック実行..."
./scripts/health_check.sh

# 5. 完了
echo "5/5: セットアップ完了"
echo "✅ 開発環境の準備が整いました"
```

## 不明点がある場合
```bash
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 質問: 次の情報を教えてください
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

cat << 'QUESTIONS'
実行前に以下を確認させてください:

1. どのファイルを修正しますか？
   例: agents/pm_agent/automation_v11_rca.py

2. 修正の目的は？
   例: タスク並列実行機能の追加

3. バックアップは必要ですか？ (Y/n)

回答後、適切なコマンドを提示します。
QUESTIONS
```

## まとめ

**必須要件:**
1. ✅ コードブロック内に作業番号
2. ✅ 説明とコマンドを統合
3. ✅ 1回のコピペで完結
4. ✅ 選択肢は初心者向け説明付き
5. ✅ 不明点は質問形式で確認
