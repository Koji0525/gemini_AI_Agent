【問題】
何が起きた: 
1. project_goalシートで重複ヘッダーエラー

環境: Python 3.8+, Google Sheets API v4, asyncio

【原因分析】
根本原因: 初期化時の属性設定漏れとシートヘッダー管理の不備

直接原因:
1. project_goalシートのヘッダー行に空列が含まれる
   → Google Sheets APIがget_all_records()で重複エラー
2. SelfLearningPipeline.__init__でkb_managerを保存していない
   → run_learning_cycle()内でself.kb_managerにアクセスできない

【解決策】
解決手法: ヘッダークリーンアップ + 属性保存

1. project_goalヘッダー修正
# 正しいヘッダーで上書き
headers = [["goal_id", "description", "priority", "status", "created_at"]]
sheets.write_sheet('project_goal!A1:E1', headers)

2. SelfLearningPipeline修正
class SelfLearningPipeline:
    def __init__(self, sheets_manager, kb_manager):
        self.sheets_manager = sheets_manager
        self.kb_manager = kb_manager  # ← 追加必須

【学び】
1. Google Sheets APIの重複ヘッダー検出は厳密
   - 空列もヘッダーとしてカウントされる
   - 明示的にヘッダー範囲を指定すべき

2. 非同期クラスの初期化チェックリスト
   - __init__で全依存オブジェクトを保存
   - 非同期メソッドから参照する属性は必須
   - 初期化後に即座にテスト実行

3. Orchestratorパターンの注意点
   - 各コンポーネントの初期化順序が重要
   - 依存関係を明示的に注入
   - 初期化エラーは早期検出

# Orchestratorの堅牢な初期化
class Orchestrator:
    def __init__(self, dependency1, dependency2):
        # 1. 全依存を保存
        self.dep1 = dependency1
        self.dep2 = dependency2
        
        # 2. 即座に検証
        self._validate_dependencies()
        
        # 3. ヘルスチェック
        self._initial_health_check()
    
    def _validate_dependencies(self):
        """依存オブジェクトの検証"""
        required = ['dep1', 'dep2']
        for attr in required:
            if not hasattr(self, attr):
                raise ValueError(f"必須属性が未設定: {attr}")
