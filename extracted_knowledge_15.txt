タイトル: モジュールインポートパス問題
カテゴリ: Python/モジュール管理
重要度: 高

【問題】
何が起きた: モジュールインポート時にModuleNotFoundErrorが発生
環境: Python 3.8+, 複数ディレクトリ構造

【原因分析】
根本原因: パス設定とモジュール探索パスの不備
直接原因: 
1. sys.pathへのパス追加忘れ
2. 相対パスと絶対パスの混在
3. __init__.pyファイルの不足

【解決策】
解決手法: 明示的なパス追加と適切なインポート文
実装例:
# パスを明示的に追加
import sys
import os
sys.path.insert(0, os.path.join(os.path.dirname(__file__), '..'))

# 絶対インポートの使用
from package.module import ClassName

# または相対インポート
from .sibling_module import function_name

【学び】
1. プロジェクトルートをsys.pathに追加する
2. 絶対インポートと相対インポートを使い分ける
3. __init__.pyでパッケージを明示する

【予防策】
- プロジェクトのルートパスを環境変数で管理
- インポートエラーの早期検出
- パス設定を共通化

成功率: 95%
