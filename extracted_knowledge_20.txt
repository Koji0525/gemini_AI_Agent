タイトル: ロギング設定の不備問題
カテゴリ: ロギング/監視
重要度: 中

【問題】
何が起きた: デバッグ時に十分な情報が得られない、またはログが多すぎる
環境: 本番環境, デバッグ環境

【原因分析】
根本原因: ロギングレベルと出力先の設定が不適切
直接原因: 
1. 適切なロギングレベルが設定されていない
2. ログのフォーマットが統一されていない
3. 重要な情報がログに記録されていない

【解決策】
解決手法: 階層的なロギング設定と構造化ログ
実装例:
import logging
import sys

def setup_logging(level=logging.INFO):
    logger = logging.getLogger()
    logger.setLevel(level)
    
    # フォーマットの設定
    formatter = logging.Formatter(
        '%(asctime)s - %(name)s - %(levelname)s - %(message)s'
    )
    
    # コンソールハンドラー
    console_handler = logging.StreamHandler(sys.stdout)
    console_handler.setFormatter(formatter)
    logger.addHandler(console_handler)
    
    # ファイルハンドラー（必要に応じて）
    file_handler = logging.FileHandler('app.log')
    file_handler.setFormatter(formatter)
    logger.addHandler(file_handler)

# 使用例
setup_logging(logging.DEBUG)  # 開発環境
# setup_logging(logging.INFO)  # 本番環境

【学び】
1. 環境に応じてロギングレベルを調整する
2. ログメッセージは検索しやすい形式にする
3. パフォーマンス影響を考慮する

【予防策】
- ロギング設定を一元管理する
- ログローテーションを設定する
- 重要な操作は必ずログに記録する
