# task_executor/task_executor_main.py として統合

# autonomous_development_orchestrator.py で4つのタスク並行実行

class AutonomousDevelopmentOrchestrator:
    async def run_forever(self):
        tasks = [
            asyncio.create_task(self.learning_loop()),   # 30秒毎
            asyncio.create_task(self.task_loop()),       # 3分毎
            asyncio.create_task(self.status_monitor()),  # 5分毎
            asyncio.create_task(self.health_check())     # 1分毎
        ]
        await asyncio.gather(*tasks)

【学び】
1. asyncio.gather()で複数タスクを並行実行
2. 各ループは独立した周期（30秒、3分、5分、1分）
3. KeyboardInterruptで統計情報を出力して優雅に終了
4. ヘルスチェックで認証切れを自動検出・再認証
5. ステータスモニターで稼働状況を定期的に可視化

【予防策】
- 各コンポーネントは必ずSafeSheetsWrapper経由でシート操作
- sheets_schema.pyを参照してヘッダー構造を統一
- asyncio.sleep()で適切な待機時間を設定
- try-exceptで各ループのエラーを分離

【横展開】
