# Task 1: カスタム投稿タイプ作成（安全版）

**重要**: 既存の翻訳システムと競合しない安全な実装

---

## 📋 実装手順

### Step 1: バックアップ作成

**必須**: 既存の functions.php をバックアップ
```bash
WordPress管理画面 → 外観 → テーマファイルエディター
→ functions.php の内容を全てコピー
→ ローカルに "functions_backup_20251031.php" として保存
```

---

### Step 2: 新規コードの追加位置を確認

既存の functions.php の**一番最後**に追加します。

現在の最終行:
```php
add_action('init', 'register_taxonomy_skill');
```

この**直後**（ファイルの最後）に新しいコードを追加。

---

### Step 3: コードを追加

`scripts/ma_portal_functions_safe.php` の内容を**全てコピー**して、
functions.php の最後に貼り付けます。
```php
// ↑既存コード（翻訳システムなど）

add_action('init', 'register_taxonomy_skill');

// ============================================================
// M&Aポータルサイト - カスタム投稿タイプ & タクソノミー
// ============================================================
// ここに scripts/ma_portal_functions_safe.php の内容を貼り付け
```

---

### Step 4: 保存と確認

1. **「ファイルを更新」をクリック**
2. エラーが表示されないことを確認
3. WordPress管理画面の左メニューを確認

**確認項目**:
- ✅ 「M&A企業情報」メニューが表示される
- ✅ 既存の「ポートフォリオ一覧」メニューが残っている
- ✅ エラーメッセージが出ていない

---

### Step 5: 動作テスト

1. **M&A企業情報 → 新規追加** をクリック
2. テスト投稿を作成:
   - タイトル: テスト企業A
   - 本文: これはテストです
3. **公開** をクリック
4. 管理画面で投稿が表示されることを確認

---

## ⚠️ トラブルシューティング

### エラー: "Cannot redeclare function..."

**原因**: 関数名が既存コードと重複

**対処**:
1. バックアップから functions.php を復元
2. コードを確認して再度追加

### M&A企業情報メニューが表示されない

**原因**: コードが正しく保存されていない

**対処**:
1. functions.php を開く
2. 最後に追加したコードが存在するか確認
3. PHPの閉じタグ `?>` の後にコードを追加していないか確認

### 既存の機能が動作しなくなった

**原因**: コードの追加位置が間違っている

**対処**:
1. **すぐにバックアップから復元**
2. コードを最後に追加し直す
