### エラー耐性向上
```python
async def _update_progress_dashboard(self):
    try:
        updater = UnifiedProgressUpdater()
        await updater.update_progress_dashboard()
    except Exception as e:
        print(f"⚠️ 更新エラー: {e}")
        # エラーがあってもサイクルは継続
```
