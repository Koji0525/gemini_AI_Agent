# GitHub Codespaces ポート公開ガイド

## 作成日時
2025-11-23 11:35

## 問題
Flaskサーバーは起動しているが、ブラウザからアクセスできない

## 原因
GitHub Codespacesでは、ポートが自動的に公開されず、手動設定が必要

## 解決方法

### 方法1: VSCode UIで手動公開（推奨）
1. VSCodeの下部にある「ポート」タブをクリック
2. 「ポートの転送」ボタンをクリック
3. ポート番号に「5000」を入力
4. 公開されたポートの「地球儀」アイコンをクリック
5. ブラウザでダッシュボードが開く

### 方法2: devcontainer.json で自動公開
```json
{
  "forwardPorts": [5000, 5001, 5002],
  "portsAttributes": {
    "5000": {
      "label": "Flask Dashboard",
      "onAutoForward": "notify"
    }
  }
}
```

### 方法3: コマンドラインで確認
```bash
# ポート使用状況確認
lsof -i :5000

# プロセス確認
ps aux | grep python | grep web_server
```

## サーバー起動手順

### 1. サーバー起動
```bash
bash sh/start_dashboard.sh
```

### 2. ポート確認
VSCodeの「ポート」タブで5000が表示されているか確認

### 3. ブラウザアクセス
「地球儀」アイコンをクリックしてブラウザで開く

### 4. サーバー停止
```bash
bash sh/stop_dashboard.sh
```

## トラブルシューティング

### Q1: ポートタブにポートが表示されない
**A**: サーバーが起動していない可能性があります
```bash
# ログ確認
tail -f logs/dashboard.log

# プロセス確認
ps aux | grep web_server
```

### Q2: "Address already in use" エラー
**A**: ポートが既に使用されています
```bash
# 既存プロセスを停止
bash sh/stop_dashboard.sh

# 再起動
bash sh/start_dashboard.sh
```

### Q3: ブラウザで404エラー
**A**: URLパスが間違っている可能性があります
```
正しいURL: https://<codespace-name>-5000.app.github.dev/
間違い: https://<codespace-name>-5000.app.github.dev/api/health
```

ダッシュボードのトップページは `/` です。
APIエンドポイントは `/api/health` などです。

## 重要な知見

### GitHub Codespaces特有の制約
1. **ポート公開は手動またはdevcontainer.json で設定が必要**
2. **0.0.0.0 でバインドする必要がある**（127.0.0.1だと外部アクセス不可）
3. **HTTPS経由でアクセスされる**（HTTPではない）
4. **URLは動的に生成される**（固定URLではない）

### ベストプラクティス
1. devcontainer.jsonでポート設定を事前定義
2. サーバーは必ず 0.0.0.0 でバインド
3. 起動スクリプトでポート使用状況を確認
4. ヘルスチェックAPIで動作確認
