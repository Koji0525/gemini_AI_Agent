**エラー**: `SyntaxError: expected 'except' or 'finally' block`  
**重要度**: ★★★★★

---

## 🚨 エラー詳細

### 発生箇所
```
File "api_server.py", line 303
    from agents.observer_enhanced.duplicate_detector_enhanced import \
SyntaxError: expected 'except' or 'finally' block
```

### 根本原因
```python
# 不完全なtryブロック
try:
    from agents.observer_enhanced.duplicate_detector_enhanced import ...
# ← except や finally がない！
```

---

## 💡 なぜこのエラーが発生したか

### 原因1: 不適切な削除
```python
# 修正スクリプトが以下を試みた:
1. try: を残す
2. その中のimport文だけ削除
3. except/finally も削除

# 結果: try: だけが残ってしまった
```

### 原因2: 正規表現の限界
```python
# 単純な文字列置換では不十分
content = content.replace('from agents...', '')

# 問題: tryブロックの構造を認識できない
```

---

## ✅ 正しい修正方法

### 方法1: 行単位で判定
```python
lines = content.split('\n')
cleaned_lines = []

for i, line in enumerate(lines):
    # try: で始まる行を検出
    if line.strip().startswith('try:'):
        # 次の行が問題のimportなら、tryごと削除
        if 'from agents.observer_enhanced' in lines[i+1]:
            continue  # この行をスキップ
    
    cleaned_lines.append(line)
```
