## 🔍 根本原因（10層のなぜなぜ）

| なぜ | 答え | 学び |
|------|------|------|
| 1. なぜv31を使った？ | 最新だと思い込んだ | **思い込み禁止** |
| 2. なぜv51に気づかない？ | ls確認しなかった | **必ず確認** |
| 3. なぜ確認しない？ | パスが正しければOKと思った | **バージョン確認必須** |
| 4. なぜバージョン不明？ | 管理方針がない | **ガバナンス必要** |
| 5. なぜ方針ない？ | ファイル名依存 | **仕組み化** |
| 6. なぜファイル名依存？ | シンボリックリンクなし | **リンク作成** |
| 7. なぜリンクなし？ | 初期は1ファイル | **スケール対応** |
| 8. なぜスケール未対応？ | 規約未確立 | **規約策定** |
| 9. なぜ規約なし？ | チーム議論なし | **議論実施** |
| 10. なぜ議論なし？ | AI開発で急成長 | **ガバナンス追従** |

## 💡 **真因**
```
「最新バージョンを自動的に特定・利用する仕組みが存在せず、
開発者の推測に依存している」
```

## 🎓 **重要な教訓**

### 教訓1: 「思い込み」は最大の敵
```
❌ 「このパスなら正しいはず」
❌ 「この名前なら最新のはず」
❌ 「前回これで動いたから」

✅ 「実際に確認する」
✅ 「ドキュメントを見る」
✅ 「最新版を特定する」
```

### 教訓2: スケールに合わせてガバナンスを進化させる
```
小規模: ファイル名で管理 OK
中規模: シンボリックリンク必須
大規模: バージョン管理システム必須
```

### 教訓3: 2回繰り返したら仕組み化
```
1回目: 偶然のエラー → 対症療法
2回目: パターン → 分析開始
3回目: システム問題 → 仕組み化 ← 今ここ
```
