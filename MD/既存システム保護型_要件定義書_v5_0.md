## 1. 基本方針

### 1.1 システム改良の大原則

**【絶対原則】既存システムは1行も破壊しない**

- 既存ファイルの変更は file_version_manager.py 経由のみ
- 既存テストは100%維持（現在84.3%を下回らない）
- 既存機能は完全保護（バックワード互換性必須）
- 追加開発のみ（上書き・削除は厳禁）

### 1.2 品質向上の目標値

| 指標 | 現状 | 目標 | 根拠 |
|------|------|------|------|
| タスク実行出力行数 | 50-100行 | 1000行以上 | 5万行プロジェクトの実用性確保 |
| ファイル生成数/タスク | 1ファイル | 3ファイル以上 | main + test + README構成 |
| README.md行数 | なし | 300行以上 | 運用・保守性確保 |
| テスト成功率 | 84.3% | 90%以上 | 品質基準向上 |
| タスク分解精度 | 簡易版 | 1500-2000文字 | 具体的な作業指示 |
| 24時間稼働安定性 | 未検証 | 99%以上 | 実用システム基準 |

**目標値の根拠**:
- 1000行: 5万行システムを50タスクで構築する想定（50タスク × 1000行 = 5万行）
- 3ファイル: 実装 + テスト + ドキュメントの最小セット
- 300行README: インストール(50行) + 使用方法(100行) + API仕様(50行) + 開発者向け(100行)
- 90%成功率: 10タスクで1回失敗まで許容（実用的品質）
- 1500-2000文字: 目的(200字) + 作業内容(700字) + 成功基準(300字) + 前提条件(300字) + 制約(300字)

### 1.3 開発環境

- **実行環境**: GitHub Codespaces
- **Python**: 3.10+
- **主要ライブラリ**: google-generativeai, gspread, faiss-cpu, sentence-transformers
- **データベース**: SQLite (knowledge.db)

# SelfHealingAgentの拡張
class EnhancedSelfHealingAgent(SelfHealingAgent):
    
    def detect_quality_issues(self, task_result: Dict) -> List[str]:
        """品質問題の検出"""
        issues = []
        
        if task_result.get('total_lines', 0) < 500:
            issues.append("output_too_small")
        
        if task_result.get('file_count', 0) < 2:
            issues.append("insufficient_files")
        
        if not task_result.get('has_readme'):
            issues.append("missing_readme")
        
        return issues
    
    def auto_fix_quality(self, task_data: Dict, issues: List[str]):
        """品質問題の自動修正"""
        if "output_too_small" in issues:
            # より詳細なプロンプトで再実行
            enhanced_prompt = self._enhance_prompt_for_scale(task_data)
            return self.retry_with_enhanced_prompt(task_data, enhanced_prompt)

### 7.2 継続的品質監視
````python
# scripts/continuous_quality_monitor.py
class ContinuousQualityMonitor:
    def __init__(self):
        self.metrics_history = []
        self.alert_threshold = {
            'avg_lines': 800,      # 最低800行
            'success_rate': 75,    # 最低75%
            'file_count': 2.5      # 最低2.5ファイル
        }
    
    def record_execution(self, task_id: str, result: Dict):
        """タスク実行結果を記録"""
        metrics = {
            'timestamp': datetime.now(),
            'task_id': task_id,
            'total_lines': result.get('total_lines', 0),
            'file_count': result.get('file_count', 0),
            'success': result.get('success', False)
        }
        self.metrics_history.append(metrics)
        
        # リアルタイムチェック
        self._check_thresholds(metrics)
    
    def _check_thresholds(self, metrics: Dict):
        """閾値チェック"""
        if metrics['total_lines'] < self.alert_threshold['avg_lines']:
            self._send_alert(
                f"⚠️  出力行数不足: {metrics['total_lines']}行 "
                f"（目標: {self.alert_threshold['avg_lines']}行）"
            )
````
