## Phase 5で実装した全機能

### スクリプト1: Flask Webサーバー + REST API
**実装内容**:
- FlaskベースのWebサーバー（ポート5000）
- 8つのREST APIエンドポイント
- Phase 4コンポーネント統合（MetricsCollector、PerformanceMonitor）

**アクセス**: http://localhost:5000

### スクリプト2: 完全版ダッシュボード（Chart.js統合）
**実装内容**:
- Bootstrap 5による美しいUI
- Chart.jsリアルタイムグラフ（CPU、メモリ、ディスク）
- システム健全性スコア（0-100点、A-Fグレード）
- 15エージェント状態表示
- タスク統計（総数、完了、失敗）
- 5秒ごと自動更新

**アクセス**: http://localhost:5000/

### スクリプト3: 依存関係ネットワークグラフ（D3.js）
**実装内容**:
- D3.js Force Layoutで全ファイルの繋がりを可視化
- .py、.sh、.md等すべてのファイルをスキャン
- インタラクティブなネットワークグラフ
- ノードクリックで影響範囲表示
- カテゴリ別色分け（agent/tool/test/script/doc）
- Top 10ファイル表示

**アクセス**: http://localhost:5000/dependencies

**主な機能**:
- ✅ 全ファイルの依存関係を一目で理解
- ✅ ファイル変更時の影響範囲を即座に把握
- ✅ どこを壊すと何が壊れるか可視化

### スクリプト4: 重複検出&問題分析
**実装内容**:
- 重複ファイル自動検出（v01, v02等）
- 未使用ファイル検出（被インポート0）
- 汎用的に再利用できるツール推奨
- バージョン履歴可視化
- 推奨アクション自動生成
- データエクスポート（JSON/CSV/HTML）

**アクセス**: http://localhost:5000/analysis

**主な機能**:
- ✅ 重複開発されたファイルを検出
- ✅ 未使用で眠っているファイルを発見
- ✅ 汎用的に使えるのに活用されていないツールを推奨

## 全体で解決した課題

### 課題1: 何と何が繋がっているか分からない
**解決**: 
- 依存関係ネットワークグラフで一目瞭然
- D3.jsで全ファイルの繋がりを可視化
- ノードをクリックすると影響範囲を表示

### 課題2: どこを壊すと何が壊れるか分からない
**解決**:
- ファイルクリックで影響を受けるファイル一覧表示
- 直接影響と間接影響を区別
- 再帰的な依存関係追跡

### 課題3: 重複開発が多数ある
**解決**:
- file_version_manager.py連携で重複検出
- 最新バージョンを自動判定
- 重複グループごとに表示

### 課題4: 汎用的なツールが眠っている
**解決**:
- tools/ディレクトリの未活用ツールを推奨
- ファイルサイズと使用頻度で判定
- 再利用促進のための情報提供

## アクセス方法

### GitHub Codespaces環境
1. VSCodeの「ポート」タブを開く
2. ポート5000の「地球儀🌐」アイコンをクリック
3. ブラウザで以下のページが利用可能:
```
📊 メインダッシュボード
http://localhost:5000/

🕸️ 依存関係グラフ
http://localhost:5000/dependencies

🔍 問題検出
http://localhost:5000/analysis
```

### 確認すべきポイント

#### メインダッシュボード (/)
- [ ] システム健全性スコアが表示されているか
- [ ] リアルタイムグラフが動作しているか（5秒ごと更新）
- [ ] CPU、メモリ、ディスクの数値が表示されているか
- [ ] 15エージェントのバッジが表示されているか

#### 依存関係グラフ (/dependencies)
- [ ] ネットワークグラフが表示されているか
- [ ] ノード（点）とエッジ（線）が描画されているか
- [ ] ノードをドラッグできるか
- [ ] ノードをクリックすると影響範囲が表示されるか
- [ ] 統計情報が表示されているか

#### 問題検出 (/analysis)
- [ ] 重複ファイル数が表示されているか
- [ ] 未使用ファイル数が表示されているか
- [ ] 再利用可能ツール数が表示されているか
- [ ] 推奨アクションが表示されているか

## トラブルシューティング

### Q1: ダッシュボードが真っ白
**A**: ブラウザのキャッシュをクリア（Ctrl+Shift+R）

### Q2: グラフが表示されない
**A**: 
1. F12で開発者ツールを開く
2. Consoleタブでエラーを確認
3. NetworkタブでAPI呼び出しを確認

### Q3: データが0件
**A**: 
```bash

curl http://localhost:5000/api/dependencies/scan
curl http://localhost:5000/api/analysis/report
```

- 🔍 問題検出
のボタンがあります
