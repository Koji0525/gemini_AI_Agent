### 3. Force-Directed Graphの実装パターン

**実装コード**:
```javascript
// Force-Directed Graphの標準パターン
simulation = d3.forceSimulation(nodes)
    .force('link', d3.forceLink(edges).distance(100))
    .force('charge', d3.forceManyBody().strength(-300))
    .force('center', d3.forceCenter(width / 2, height / 2))
    .force('collision', d3.forceCollide().radius(30));

simulation.on('tick', () => {
    // ノード/エッジの位置を更新
    link.attr('x1', d => d.source.x)...
    node.attr('cx', d => d.x)...
    label.attr('x', d => d.x)...
});
```

**力学パラメータの調整**:
| パラメータ | 値 | 効果 |
|---|---|---|
| link.distance | 100 | ノード間の距離 |
| charge.strength | -300 | 反発力（負=反発） |
| collision.radius | 30 | 衝突検出半径 |

**教訓**:
> **「D3.jsの力学モデルは調整が重要」**
> 
> - 距離が近すぎると重なる
> - 反発力が弱すぎると団子状態
> - 衝突検出で重なりを防止

### 5. データ変換の重要性

**問題**:
```javascript
// APIから返ってくるデータ
{
  nodes: [{id: "agents/pm_agent.py"}, ...],
  edges: [{source: "agents/pm_agent.py", target: "utils/db.py"}, ...]
}

// D3.jsが期待するデータ（インデックス）
{
  nodes: [{id: "agents/pm_agent.py"}, ...],
  edges: [{source: 0, target: 5}, ...]  // インデックス
}
```

**解決策**:
```javascript
// ノードIDをインデックスに変換（P3-002）
const nodeMap = new Map();
graphData.nodes.forEach((node, index) => {
    nodeMap.set(node.id, index);
});

graphData.edges = graphData.edges.map(edge => ({
    source: nodeMap.get(edge.source),
    target: nodeMap.get(edge.target),
})).filter(edge => edge.source !== undefined);
```

**教訓**:
> **「APIデータとライブラリの形式は異なる」**
> 
> - データ変換層が必要
> - 不正なエッジを除外
> - エラーハンドリング重要
