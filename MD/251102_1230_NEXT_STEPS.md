## ✅ ステップ2: GitHub Secrets設定

### 設定する値

#### 1. GOOGLE_CREDENTIALS
```
configuration/service_account.json の内容全体をコピー
```

**取得方法:**
```bash
cat configuration/service_account.json
```

**設定手順:**
1. GitHubリポジトリ > Settings > Secrets and variables > Actions
2. "New repository secret"をクリック
3. Name: `GOOGLE_CREDENTIALS`
4. Secret: JSONの内容全体をペースト
5. "Add secret"をクリック

#### 2. SPREADSHEET_ID
```
スプレッドシートのIDをコピー
```

**取得方法:**
```bash
grep SPREADSHEET_ID .env
```
または、スプレッドシートのURLから取得:
```
https://docs.google.com/spreadsheets/d/【ここがSPREADSHEET_ID】/edit
```

**設定手順:**
1. GitHubリポジトリ > Settings > Secrets and variables > Actions
2. "New repository secret"をクリック
3. Name: `SPREADSHEET_ID`
4. Secret: スプレッドシートIDをペースト
5. "Add secret"をクリック

### 設定確認
設定後、以下のコマンドで確認できます:
```bash
# GitHub CLIを使用
gh secret list
```

## ✅ ステップ3: 初回実行テスト

### 3-1. テスト目標の準備

スプレッドシートの`project_goal`シートに手動でテスト目標を追加:

| goal_id | description | priority | status | progress | created_at |
|---------|------------|----------|--------|----------|------------|
| TEST_001 | テスト: シンプルなタスク実行確認 | high | active | 0% | 2025-11-02T12:00:00 |

### 3-2. GitHub Actionsで手動実行

1. **GitHubリポジトリのActionsタブを開く**
```
   https://github.com/<your-username>/<your-repo>/actions
```

2. **ワークフローを選択**
   - 左サイドバーから「24時間自律開発システム」を選択

3. **Run workflowをクリック**
   - 右上の「Run workflow」ボタンをクリック

4. **テスト目標を入力**
```
   目標: テスト実行 - システム動作確認
   優先度: high
```

5. **実行開始**
   - 「Run workflow」を再度クリック

6. **ログを確認**
   - 実行が開始されたら、ワークフロー名をクリック
   - 各ステップのログを確認

### 3-3. 期待される動作
```
✅ 認証情報セットアップ完了
✅ 目標登録完了
✅ PM Agentが目標を分解
✅ タスクがpm_tasksに登録
✅ Task Coordinatorがタスク実行
✅ 実行結果がtask_execution_logに記録
```

### 3-4. トラブルシューティング

**エラー: 認証失敗**
```
原因: GitHub Secretsが正しく設定されていない
対処: ステップ2を再確認
```

**エラー: シートが見つからない**
```
原因: 重複シートが削除されていない、またはマッピングが機能していない
対処: 
1. ステップ1を実行
2. ローカルでテスト: python3 tools/sheets_manager.py
```

**エラー: タスクが実行されない**
```
原因: project_goalにactiveな目標がない
対処: project_goalシートでstatusを'active'に設定
```

## 🚨 アラート設定（推奨）

### GitHub Actions失敗時の通知

**Slackへの通知（オプション）:**
```yaml
# .github/workflows/autonomous_dev_system.ymlに追加
- name: Slack通知
  if: failure()
  uses: 8398a7/action-slack@v3
  with:
    status: ${{ job.status }}
    text: '自律開発システムが失敗しました'
    webhook_url: ${{ secrets.SLACK_WEBHOOK }}
```

### スプレッドシートの監視

**Google Apps Scriptで異常検知:**
```javascript
function checkSystemHealth() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName('pm_tasks');
  var data = sheet.getDataRange().getValues();
  
  var failedCount = 0;
  for (var i = 1; i < data.length; i++) {
    if (data[i][3] === 'failed') {
      failedCount++;
    }
  }
  
  if (failedCount > 5) {
    // アラート送信
    MailApp.sendEmail({
      to: 'your-email@example.com',
      subject: '🚨 システムアラート: 失敗タスク多数',
      body: `${failedCount}個のタスクが失敗しています`
    });
  }
}
```
