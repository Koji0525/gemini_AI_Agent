## 💡 重要な教訓

### 教訓1: ファイルパスは絶対パス基準で
```python
# ❌ 悪い例
graph_file = Path("docs/dependency_map.json")

# ✅ 良い例
project_root = Path(__file__).parent.parent.parent
graph_file = project_root / "docs" / "dependency_map.json"
```

### 教訓2: グローバル変数は明示的に
```python
# ファイル先頭で定義
graph_data = None

def load_data():
    global graph_data  # 明示的に宣言
    graph_data = {...}
```

### 教訓3: データ読み込みは冗長性を
```python
# 複数回チェック
if graph_data is None:
    load_data()

if len(graph_data.get("nodes", [])) == 0:
    load_data()  # 空なら再読み込み
```

### 教訓4: エラーは詳細にログ出力
```python
logger.info(f"📂 ファイルパス: {graph_file}")
logger.info(f"✅ ノード数: {len(nodes)}")
logger.error(f"❌ エラー詳細: {e}")
logger.error(traceback.format_exc())
```

### 教訓5: 失敗した対策も記録する
```
- ModuleNotFoundError → インライン実装
- 相対パス失敗 → 絶対パス
- JSON再生成のみでは不十分 → API修正も必須
```
