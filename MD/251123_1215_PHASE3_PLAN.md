## 📊 Phase 3タスク分解

### Task 3-1: Git Hooks統合（半日）

**目標**: コミット前に自動で依存関係分析を実行

**実装ファイル**:
```
.git/hooks/pre-commit          # コミット前フック
scripts/ci/pre_commit_check.py  # チェックスクリプト
```

**機能**:
- コミット前に変更ファイルの影響範囲を分析
- 高リスクファイル変更時に警告表示
- 破壊的変更検知時に確認プロンプト

**フロー**:
```
git commit
  ↓
pre-commitフック起動
  ↓
変更ファイル検出
  ↓
影響範囲分析
  ↓
リスクスコア計算
  ↓
高リスク時は確認プロンプト
  ↓
OK → コミット実行
NG → コミット中止
```

---

### Task 3-2: GitHub Actions統合（1日）

**目標**: PR時に自動で依存関係レポートを生成

**実装ファイル**:
```
.github/workflows/dependency_check.yml  # GitHub Actions
scripts/ci/generate_pr_report.py        # レポート生成
```

**機能**:
- PR作成時に依存関係分析を自動実行
- 変更の影響範囲をコメントで投稿
- リスクスコアをラベル付け（high/medium/low）

**レポート内容**:
```markdown
## 📊 依存関係分析レポート

### 変更ファイル
- `tools/sheets_manager.py` (変更)

### 影響範囲
- **高影響**: 244ファイルに影響
- **リスクスコア**: 30/100 (Medium)

### 推奨事項
- ⚠️ 244個のファイルから依存されています
- 変更時は影響範囲テストが必須です
- 段階的なデプロイを推奨します

### テスト推奨範囲
1. `integrated_task_manager.py`
2. `autonomous_development_orchestrator.py`
...（上位10ファイル）
```

---

### Task 3-3: 自動テスト推奨（半日）

**目標**: 影響範囲から必要なテストファイルを自動提案

**実装ファイル**:
```
scripts/ci/suggest_tests.py  # テスト推奨エンジン
```

**機能**:
- 変更ファイルの依存関係から影響を受けるファイルを抽出
- 対応するテストファイルを検索
- 実行すべきテストコマンドを生成

**出力例**:
```bash
# 推奨テストコマンド
pytest tests/test_sheets_manager.py
pytest tests/test_integrated_task_manager.py
pytest tests/integration/test_sheets_integration.py
```

### Task 3-4: 継続的監視（1日）

**目標**: 定期的に依存関係を監視し、変化を検知

**実装ファイル**:
```
scripts/ci/scheduled_analysis.py   # 定期分析
scripts/ci/notify_changes.py       # 変更通知
```

**機能**:
- 毎日深夜に依存関係を自動分析
- 前日との差分を検出
- 新しい高影響モジュールを検出
- Slack/メール通知

**通知内容**:
```
🔔 依存関係変更検知

新規高影響モジュール:
- tools/new_utility.py (10ファイルから依存)

リスクスコア変化:
- tools/sheets_manager.py: 30 → 35 (+5)
```

## 🚨 リスク管理

### リスク1: Git Hook の無効化
**内容**: ユーザーが`--no-verify`でスキップ
**対策**: GitHub Actions で二重チェック

### リスク2: 分析時間の長大化
**内容**: 大規模PRで分析に時間がかかる
**対策**: 差分ファイルのみ分析

### リスク3: 誤検知
**内容**: 低リスク変更で警告が出る
**対策**: 閾値調整、ホワイトリスト
