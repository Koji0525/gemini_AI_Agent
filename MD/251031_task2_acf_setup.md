# Task 2: ACFカスタムフィールド設定

**所要時間**: 10分
**前提条件**: Task 1完了（ma_company投稿タイプが存在）

---

## 📋 準備: Advanced Custom Fields プラグインのインストール

### プラグインの確認

WordPress管理画面 → プラグイン → インストール済みプラグイン

**ACFが既にインストールされているか確認**:
- ✅ 既にある → そのまま次へ
- ❌ ない → 以下の手順でインストール

### インストール手順

1. プラグイン → 新規追加
2. 検索: "Advanced Custom Fields"
3. 「今すぐインストール」→「有効化」

---

## 🔧 フィールドグループの作成

### Step 1: 新規フィールドグループ作成

1. **ACF → フィールドグループ → 新規追加**
2. フィールドグループ名: `企業詳細情報`

---

### Step 2: フィールドを追加（5個）

#### フィールド1: 所在地
```
フィールドラベル: 所在地
フィールド名: location
フィールドタイプ: テキスト
必須?: はい
プレースホルダーテキスト: 例: 東京都渋谷区
```

#### フィールド2: 資本金
```
フィールドラベル: 資本金（万円）
フィールド名: capital
フィールドタイプ: 数値
必須?: はい
最小値: 0
プレースホルダーテキスト: 例: 10000
```

#### フィールド3: 従業員数
```
フィールドラベル: 従業員数
フィールド名: employees
フィールドタイプ: 数値
必須?: はい
最小値: 0
プレースホルダーテキスト: 例: 50
```

#### フィールド4: 年商
```
フィールドラベル: 年商（万円）
フィールド名: revenue
フィールドタイプ: 数値
必須?: はい
最小値: 0
プレースホルダーテキスト: 例: 100000
```

#### フィールド5: 希望条件
```
フィールドラベル: 希望条件
フィールド名: deal_type
フィールドタイプ: 選択
必須?: はい
選択肢:
  売却希望 : 売却希望
  買収希望 : 買収希望
デフォルト値: 売却希望
UI: ラジオボタン
```

---

### Step 3: 表示ルールの設定

**位置**: ページ下部の「位置」セクション
```
ルール:
  投稿タイプ が 次と等しい ma_company
```

**設定**:
- スタイル: デフォルト
- 位置: 通常（タイトルの後）
- 説明のラベル: 上部に表示

---

### Step 4: 公開

右上の「公開」ボタンをクリック

---

## ✅ 動作確認

1. **M&A企業情報 → 新規追加**
2. 編集画面を確認:
   - タイトル入力欄の下に「企業詳細情報」セクションが表示
   - 5つのフィールドが表示される
   - 各フィールドが正しく動作する

3. テスト投稿を作成:
```
   タイトル: テスト企業B
   所在地: 東京都千代田区
   資本金: 5000
   従業員数: 30
   年商: 50000
   希望条件: 売却希望
```

4. **公開**して保存されることを確認
