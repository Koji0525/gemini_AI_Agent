## 📝 引き継ぎ事項（将来のメンテナンス用）

### 日常的なメンテナンス
```bash
# コード修正時
./wp-deploy

# 新規ページ追加時
python3 tools/wp_auto_complete.py

# トラブル時
python3 tools/wp_plugin_manager.py --diagnose
```

### 重要な注意点

1. `.env`ファイルは `chmod 444` で保護済み
2. キャッシュクリアは `./scripts/clean_cache.sh` で実行
3. バックアップは `_BACKUP/` に自動保存
