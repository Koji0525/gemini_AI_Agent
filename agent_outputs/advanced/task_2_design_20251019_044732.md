# タスク 2: design

**概要**: 企業（案件）基本情報、売り手企業情報、買い手企業情報に対応するWordPressカスタム投稿タイプ（CPT）とカスタムフィールド（ACFなどのプラグイン利用前提）の具体的な設計定義書作成

**前提情報**: 依存タスクの出力を参照

---

ご依頼ありがとうございます。デザインの専門家として、M&Aマッチングプラットフォームで必要となる企業（案件）基本情報、売り手企業情報、買い手企業情報に対応するWordPressカスタム投稿タイプ（CPT）とカスタムフィールド（ACFなどのプラグイン利用前提）の具体的な設計定義書を作成します。この設計は、コンテンツの構造化、ユーザー（システム管理者、売り手、買い手）の入力体験、および将来的な表示・検索・フィルタリングの柔軟性を最大限に高めることを目的としています。M&Aマッチングプラットフォーム向け WordPress CPT & カスタムフィールド 設計定義書1. カスタム投稿タイプ（CPT）の定義CPT スラッグ名称概要役割/利用ユーザー公開設定ma_case案件情報個別のM&A案件情報（売り手と買い手のマッチング基盤となる情報）。マッチングの核となるコンテンツ。システム管理者、プラットフォーム登録ユーザー（売り手・買い手）が閲覧。非公開（ログインユーザー限定）またはカスタム権限設定seller_company売り手企業案件の提供元となる企業（売り手）の詳細情報。案件情報と紐づく企業情報。売り手が自ら入力・更新。非公開（ログインユーザー限定）またはカスタム権限設定buyer_company買い手企業M&Aに関心を持つ企業（買い手）の詳細情報。買い手側プロファイル情報。買い手が自ら入力・更新。非公開（ログインユーザー限定）またはカスタム権限設定Export to Sheets2. カスタムフィールド（ACFなど）設計定義すべてのカスタムフィールドは、Advanced Custom Fields (ACF) のようなプラグインを利用して実装することを前提とします。2.1.
