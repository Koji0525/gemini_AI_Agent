## 💡 出力例

【ナレッジ登録開始】
タイトル: 属性・メソッド不足問題
カテゴリ: コンポーネント設計
重要度: 高

【問題】
何が起きた: コンポーネントの属性・メソッド不足エラー
環境: Python 3.8+, 非同期処理環境

【原因分析】
根本原因: コンポーネントのインターフェース実装が不完全
直接原因: 
1. GoogleSheetsManagerにauthenticated属性がなかった
2. KnowledgeBaseManagerにupdateメソッドがなかった

【解決策】
解決手法: インターフェース完全実装パターン
実装例:
class GoogleSheetsManager:
    def __init__(self):
        self.authenticated = False

class KnowledgeBaseManager:
    async def update(self, patterns):
        for pattern in patterns:
            await self._process_pattern(pattern)

【学び】
1. クラスの必須属性を__init__で明示的に定義する
2. インターフェースメソッドは実際に実装する

【予防策】
- インターフェース契約テストの作成
- コンポーネントの単体テストでメソッド存在を確認

成功率: 97%
