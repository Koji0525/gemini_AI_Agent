### 2. 判断支援システム
**特徴:**
- 過去の成功例参照
- 4タイプの提案（fix/retry/escalate/fallback）
- 信頼度スコア計算
- 自動実行判定

**判断パターン:**
```
エラー発生
  ↓
類似ケース検索
  ↓
├─ 修正レシピあり → fix提案（高信頼度）
├─ 成功例あり → retry提案（中信頼度）
├─ 失敗頻発 → escalate提案（低信頼度）
└─ ナレッジなし → fallback提案（基本対応）
```

```python

    類似度 × 0.4 +
```
