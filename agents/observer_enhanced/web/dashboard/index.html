ファイル検索

検索のヒント: ファイル名の一部を入力してください（例: sheets_manager）

リスク評価基準

高リスク: 20個以上のファイルから参照
変更時は慎重に。広範囲への影響があります。
中リスク: 10-19個のファイルから参照
変更前にテストを実行してください。
低リスク: 1-9個のファイルから参照
比較的安全に変更できます。
未使用: どこからも参照されていません
削除を検討できます。

推奨事項

  • 高リスクファイルは慎重に変更
  • 変更前にテストを実行
  • 未使用ファイルは削除を検討
  • 定期的に依存関係を見直す

利用可能なAPI

以下のAPIエンドポイントが利用可能です。クリックして直接アクセスできます。

GET /api/dependencies
依存関係データを取得（1363ノード、17024エッジ） GET /api/signals
信号機データを取得（リスク評価付き） GET /docs
Swagger UI（API仕様書、インタラクティブ） GET /redoc
ReDoc（API仕様書、読みやすい形式）
API使用例:
curl http://localhost:8001/api/dependencies | jq
