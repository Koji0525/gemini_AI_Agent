# 完全自動化Git統合ワークフロー

## 🎯 概要

STEP 1-9までを**ワンコマンド**で実行する完全自動化システム

---

## 🚀 使い方

### 基本的な使い方
```bash
python3 agents/git_agent/auto_commit_push.py "コミットメッセージ"
```

### オプション
```bash
# プッシュしない（コミットのみ）
python3 agents/git_agent/auto_commit_push.py "メッセージ" --no-push

# 設定ファイル指定
python3 agents/git_agent/auto_commit_push.py "メッセージ" --config custom_config.yaml
```

---

## 📋 実行されるステップ

| STEP | 項目 | 説明 |
|------|------|------|
| 1 | CLEANUP | 一時ファイルを_WIPに移動 |
| 2 | LIST | コミット対象を列挙 |
| 3 | SECURITY CHECK | 認証ファイル検出 |
| 3 | DUPLICATE CHECK | 重複メソッド検出 |
| 3 | COMPILE CHECK | 構文チェック |
| 5 | TEST | **開発プログラムのテスト**（対話式） |
| 6 | FINAL CLEANUP | 不要ファイル削除 |
| 8 | UPDATE .gitignore | 必要なパターンを追加 |
| 9 | COMMIT & PUSH | コミット＋プッシュ |

---

## 💡 STEP 5: テストについて

開発プログラムのテストは**対話式**です：
```bash
📝 開発したプログラムのテストコマンドを入力してください
   例: DISPLAY=:1 python3 agents/pm_agent/automation.py
   例: python3 scripts/test_integration.py
   スキップする場合は Enter のみ押してください

テストコマンド: _
```

### テストが失敗した場合
```bash
❌ テスト失敗（終了コード: 1）

テスト失敗を無視してコミットしますか？ (y/N):
```

- `y`: テスト失敗を無視してコミット続行
- `N`: ワークフロー中断

---

## 🔒 セキュリティ機能

### 認証ファイル自動検出

以下のパターンを自動検出：
- `service_account.json`
- `**/*_key.json`
- `**/*.pem`
- `**/credentials.json`
- `**/.env`

検出された場合、**自動的にワークフロー中断**

## ⚙️ 設定

`configs/git_workflows/auto_workflow_config.yaml` で設定可能
```yaml
quality_gates:
  test: true            # テストを実行
  security_check: true  # 認証ファイル検出
  duplicate_check: true # 重複メソッド検出
```

## 🚨 トラブルシューティング

### Push Protection発動
```
❌ プッシュ失敗:
   GitHub Push Protectionが発動しました
   認証ファイルが検出されています
```

**対処法:**
1. 認証ファイルを`.gitignore`に追加
2. `git filter-branch`で履歴から削除
3. 認証情報を無効化＆再発行

### 重複メソッド検出
```
❌ 重複メソッドが検出されました:
   ❌ task_executor.py
      - TaskExecutor.execute: 行 [13, 41]
```

**対処法:**
1. 重複メソッドを手動で削除
2. 再実行
